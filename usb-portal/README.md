# Портал сотрудников УСБ УВД по ЦАО (RMRP)

Портал с входом по аккаунтам, профилями сотрудников, новостями и админ-панелью.
Сервер: Node.js + Express. Данные хранятся в JSON-файле, сборка фронтенда не нужна.

## Запуск

Нужен Node.js 22.9 или новее. Как разместить портал на сервере — в [DEPLOY.md](DEPLOY.md).

```
npm install
npm start
```

Откройте http://localhost:3000.

При первом запуске сервер создаёт 4 учётные записи администраторов со случайными логинами и паролями
и записывает их в `data/admin-credentials.txt`. Передайте данные администраторам и удалите файл:
в базе хранятся только хеши паролей.

Для разработки с автоперезапуском: `npm run dev`.

### Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `PORT` | порт сервера | `3000` |
| `DATA_DIR` | папка с базой и загруженными изображениями | `./data` |
| `COOKIE_SECURE` | `1` — cookie только по HTTPS (включите на сервере с HTTPS) | выключено |
| `TRUST_PROXY` | `1` — сервер стоит за обратным прокси (nginx и т. п.) | выключено |

## Как устроено

- Без входа доступна только страница входа. Остальные страницы и API требуют аккаунт.
- Аккаунты создаёт администратор в админ-панели. Самостоятельной регистрации нет.
- Админ-панель (`/admin.html`) открыта только администраторам.
- Сотрудник может менять в своём профиле аватар, баннер, подпись для документов и пароль. Остальные данные меняет администратор.
- Новости публикуют, редактируют и удаляют администраторы, читают все вошедшие сотрудники.

### Тема оформления

Кнопка с луной/солнцем в шапке переключает светлую и тёмную тему. Выбор запоминается в браузере;
пока его не сделали, используется тема операционной системы. Цвета обеих тем — переменные в начале `style.css`.

### Чат сотрудников (главная страница)

- Писать могут все вошедшие сотрудники без мута. Лента обновляется каждые 3 секунды.
- История: хранятся последние 5000 сообщений. Сначала показываются 50 последних, более ранние подгружаются
  кнопкой «Показать более ранние сообщения» или прокруткой вверх. Сообщения разделены по дням.
- Администратор может очистить весь чат одной кнопкой «Очистить чат» (с подтверждением);
  в чате остаётся системная запись о том, кто его очистил.
- Сотрудник может изменять и удалять только свои сообщения. Администратор — любые, включая системные.
- Модерация (только для администраторов, только в отношении сотрудников, не администраторов) — из чата
  (кнопки при наведении на сообщение) или из админ-панели (колонка «Чат»):
  - предупреждение с обязательной причиной; на 3-м предупреждении автоматически выдаётся мут на 1 час, счётчик обнуляется;
  - мут с обязательной причиной и сроком (от 1 минуты до 30 дней);
  - снятие мута.
- Под мутом нельзя писать и изменять свои сообщения (удалять свои — можно).
- В профиле сотрудник видит срок мута, остаток, причину и кто его выдал, а также свои действующие предупреждения.
- О каждом предупреждении, муте и снятии мута в чат пишется системное сообщение.

### Документы

- **Конструктор** (`/constructor.html`, ссылка — на странице «Документооборот»): сотрудник выбирает шаблон
  и заполняет только поля из фигурных скобок. Остальной текст не редактируется. Справа — предпросмотр листа A4
  с подсветкой полей. Готовый документ можно скачать в PNG и отправить в документооборот.
- ФИО, звание, должность и инициалы подставляются из профиля, номер — автоматически (их можно исправить).
  Номер: `ггд-дмм-X` — две последние цифры года и первая цифра дня, вторая цифра дня и месяц,
  порядковый номер документа за сегодня (по московскому времени). Например, 24.10.2026 → `262-410-1`.
- Даты из квадратных скобок ставятся сегодняшние в формате образца (`[«24» октября 2026 г.]`, `[22 октября 2026 года]`,
  `[24.10.2026]`). Их можно изменить в блоке «Даты».
- **Подпись** сотрудник загружает картинкой или рисует в профиле. Она ставится в документ автоматически.
  Без подписи документ с местом для подписи отправить нельзя. В отправленном документе хранится копия подписи,
  поэтому её последующая смена не меняет старые документы.
- Если документ чуть не помещается на один лист, межстрочный интервал автоматически сжимается (до 1,06),
  чтобы подпись не уходила на вторую страницу. Длинные документы занимают несколько листов с обычным интервалом.
- Шаблон по умолчанию, который администратор не менял, при запуске сервера обновляется до новой версии
  (так в приказ добавился герб). Изменённые вручную шаблоны не трогаются.
- **Админ-панель → Документооборот** (только администраторы): список отправленных документов с поиском,
  отметкой «Новый» и счётчиком непрочитанных; просмотр, скачивание PNG, удаление.
- **Админ-панель → Шаблоны**: добавление, изменение и удаление шаблонов с живым предпросмотром.
  Разметка (одна строка — один абзац):
  - `{Поле}` — заполняет сотрудник; одинаковые поля заполняются один раз;
  - `[дата]` — дата по образцу; `[подпись]`, `[печать]` — подпись сотрудника и печать;
  - `[герб]` — геральдический знак МВД; строка `^[герб]` ставит его по центру в верхнем поле листа (≈1 см от края);
  - `**текст**` — жирный, `__текст__` — курсив;
  - в начале строки: `^` — по центру, `>` — вправо, `<` — влево без отступа, `#` — заголовок,
    `~` — мелкий шрифт (сочетается с выравниванием: `~^`); без префикса — абзац по ширине с красной строкой;
  - `левая | центр | правая` — строка из колонок (например, дата, город и номер);
  - бланк в несколько колонок: `::: колонки 47/16/37` (ширины в %), строки первой колонки, `:::` — следующая колонка
    (`::: по центру` / `::: снизу` — с выравниванием по вертикали), `::: конец` — конец блока;
  - `::: поля 10 10 10 10` — поля листа в мм (верх, право, низ, лево), по умолчанию 20/15/20/30;
  - `[герб 32мм]` — герб заданной высоты; `{Номер документа}` — номер проставляется автоматически.
- Шаблоны по умолчанию: «Приказ о привлечении к дисциплинарной ответственности» и «Требование о явке для дачи объяснений».
  Каждый добавляется в базу один раз: удалённый администратором шаблон по умолчанию не возвращается.

## Структура

```
server.js                 — запуск сервера, доступ к страницам, статика
src/db.js                 — хранилище data/db.json
src/auth.js               — пароли, сеансы, проверка прав, защита от перебора
src/users.js              — проверка данных профиля
src/seed.js               — создание администраторов при первом запуске
src/images.js             — загрузка аватаров, баннеров и подписей
src/chat.js               — чат: системные сообщения, предупреждения, муты
src/doc-templates.js      — разбор разметки шаблона и шаблоны по умолчанию
src/routes/chat.js        — /api/chat: сообщения чата
src/routes/auth.js        — /api/auth: вход, выход, текущий пользователь
src/routes/profile.js     — /api/profile: аватар, баннер, подпись, смена пароля
src/routes/users.js       — /api/users: профили (только администраторы)
src/routes/news.js        — /api/news: новости
src/routes/documents.js   — /api/documents: шаблоны и документооборот
public/                   — страницы, стили, скрипты
public/assets/js/docrender.js — отрисовка документа (предпросмотр и PNG)
public/assets/img/docs/   — печать УВД по ЦАО и геральдический знак МВД для документов
data/                     — база и загрузки (создаётся автоматически, не коммитится)
```

## Резервная копия

Достаточно скопировать папку `data/`: в ней база `db.json` и загруженные изображения.
